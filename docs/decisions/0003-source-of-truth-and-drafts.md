# ADR-0003 — Источник истины, производные данные и черновики

- Статус: принято
- Дата: 2026-11-18

## Решения

1. **Источник истины — только `universe/`.** Первоисточник ТЗ — `docs/source/` (неизменяемый).
2. **Производные данные** (`build/lore/*.json`, `contradictions.md`) не коммитятся (`.gitignore`) и перестраиваются командой `lore build`. Исключение: `universe/00-meta/Реестр сущностей.md` — сгенерированный файл внутри Vault для удобства Obsidian; помечен заголовком «GENERATED», актуальность проверяется (`REGISTRY-STALE`).
3. **Энциклопедия читает `universe/` напрямую** при сборке; JSON-индексы ей не нужны и не являются вторым источником.
4. **Черновики** — `drafts/` (не валидируются как канон, не публикуются). Перенос в `universe/` — через PR с проверкой человеком.
5. **Автоматика ничего не переписывает**: валидатор и отчёт только сообщают. Единственная запись в `universe/` — перегенерация реестра командой `index`.
6. **Медиа**: тяжёлые файлы — через Git LFS (правила в `.gitattributes`); метаданные медиа (название, авторство, источник, лицензия, связанные сущности, тип) будут храниться рядом и валидироваться (Этап 6). До появления медиа реестр не создаётся.

## Последствия

- Любой новый потребитель (игра, редактор, RAG) подключается через `@archon/lore-parser`, а не через копию данных.
- Нельзя править сгенерированные файлы вручную.
