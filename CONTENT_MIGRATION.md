# CONTENT_MIGRATION — перенос существующего лора

## 1. Исходные материалы

В рабочем пространстве **не было** ни одного файла с лором (см. [`PROJECT_AUDIT.md`](PROJECT_AUDIT.md)). Единственный источник — ТЗ. Поэтому «миграция» = структурирование лора из ТЗ §2–§7.

Правила миграции:

1. **Оригинал неприкосновенен.** ТЗ сохранено дословно: `docs/source/ТЗ Archon Universe Platform.md`. Статьи — структурированное представление, а не замена.
2. **Только то, что написано в ТЗ.** Если в ТЗ факта нет — раздел статьи остаётся пустым (`—`) и пункт попадает в «Противоречия и неизвестные сведения». Пункты «Необходимо проработать» из ТЗ перенесены в статьи как список **не проработанных** тем, а не как факты.
3. **Оговорки ТЗ переносятся буквально** («предположительно», «неофициальное название», «пока считать незавершённой») — в тело статьи и в статус.
4. **Статус `canon` не присваивается** (см. `PROJECT_AUDIT.md` §5).
5. **Производные сущности** (события, концепции-заглушки) создаются только при явном упоминании в ТЗ и получают `unresolved`.
6. Каждая статья ссылается на раздел-источник ТЗ в блоке «Источники».
7. Названия файлов — русские, Title Case по ТЗ §9.5; ID — постоянные, латиницей.

## 3. Что **не** создавалось намеренно

- Категории §3.5 (организации, фракции, религии, цифровые личности и т. д.) — в ТЗ нет ни одного конкретного представителя. Поддержка типов и шаблонов есть; сущностей нет.
- Никакой глобальной хронологии, эпох, дат.
- Биографии, устройство помещений бункера, география Нейриса, архитектура Лимба и пр. — остаются в «неизвестных сведениях».
- Связь «Нейрис → технологический центр → искусственный интеллект» (ТЗ §13) отражена текстом: в базе нет сущности «искусственный интеллект» вообще, создавать её без согласования нельзя.

## 4. Проверка результата миграции

Критерии (все выполняются автоматически в `lore validate` + Vitest):

- [x] каждая сущность проходит схему и имеет уникальный ID;
- [x] все `related`/`relations` указывают на существующие ID;
- [x] все вики-ссылки и ссылки на файлы разрешаются;
- [x] у каждой статьи есть «Источники» с указанием раздела ТЗ;
- [x] оригинал ТЗ присутствует и не изменялся;
- [x] ни одна сущность не имеет `canon` без решения владельца.

Ручная проверка владельцем: открыть корень репозитория как Vault в Obsidian, пройти по `Вселенная Архон.md`, сверить статьи с ТЗ.
