# drafts — идеи до утверждения

Сюда помещаются **все новые идеи** (правило ТЗ §11.2). Содержимое `drafts/`:

- не является каноном и не валидируется как канон;
- файлы `drafts/concepts/*.md` публикуются сайтом как **черновые предложения**, не канон; не помещайте туда приватные материалы;
- остальные подпапки `drafts/` сайтом не читаются;
- не должно быть источником фактов для статей в `universe/`.

Подпапки создаются по мере необходимости (пустые не хранятся в git):

| Папка | Назначение |
|---|---|
| `inbox/` | сырые заметки и идеи (новые файлы Obsidian создаются здесь) |
| `concepts/` | оформленные концепции |
| `research/` | исследования, научные справки, референсы |
| `pending-review/` | готово к проверке Continuity Auditor/человеком |
| `abandoned/` | отвергнутое (не удаляем — сохраняем историю) |

Перенос в `universe/` — через PR с проверкой; статус при переносе не выше `review`. Автоматический перенос запрещён.

## Гипотезы для владельца

Рабочий реестр — [Гипотезы развития мира](concepts/Гипотезы%20развития%20мира.md). У каждой идеи постоянный ID `H-###`, статус, предпосылки, зависимости и последствия. Ответ по ID фиксируется как «нравится», «не нравится» или «доработать»; он не утверждает автоматически связанные идеи или канон. Отклонённые ID сохраняются и не используются повторно.
