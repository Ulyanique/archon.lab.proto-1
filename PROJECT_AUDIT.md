## 5. Решение по статусам начального лора

ТЗ говорит «все сведения ниже — исходная база», но параллельно запрещает считать часть механизмов каноном и не разрешает переносить материалы в `canon` автоматически (§11.2). Поэтому:

- сущности с чёткими утверждениями ТЗ → `review` («факт взят из ТЗ, ожидает подтверждения владельцем для перевода в `canon`»);
- сущности, про которые ТЗ прямо говорит «не установлено/не завершено/предположительно» → `unresolved`;
- `canon` **не присвоен никому**. Перевод — только явным решением владельца (Q-1).
