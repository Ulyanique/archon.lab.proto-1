# assets — медиа

Пока медиа-файлов в репозитории нет (подтверждено аудитом). Политика на будущее — ТЗ §18.

## Что и где хранить

| Тип | Каталог (создаётся при первом файле) | Хранение |
|---|---|---|
| Изображения, концепт-арт, карты, референсы | `images/`, `concept-art/`, `maps/`, `references/` | обычный git, если файл небольшой |
| Аудио, видео, 3D-модели, исходники (`*.psd`, `*.blend`, `*.kra`) | `audio/`, `video/`, `models/` | **Git LFS** (правила уже в `.gitattributes`) либо внешнее хранилище со стабильной ссылкой |

Включение LFS (один раз на клон): `git lfs install`. Без LFS тяжёлые файлы не коммитить.

## Обязательные метаданные (планируется валидация в Этапе 6)

Для каждого файла: название · описание · авторство · источник · **лицензия** · связанные сущности (ID) · тип материала. Материалы с неизвестными правами не используются как собственные и не коммитятся.

## Ссылки

Вики-ссылка `![[имя.png]]` разрешается по имени файла среди не-markdown файлов репозитория; `lore validate` сообщает о битых вложениях. Имена файлов должны оставаться стабильными.
